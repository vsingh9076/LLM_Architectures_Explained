Parts 1–5, 7 and 8 each have a Jupyter notebook with every code example from the article and the output of a run saved in it, so you can read code and results together here on GitHub. Part 6 has no code in the article, so its folder holds only the script for one of its animations; Part 9 has scripts, logs and figure scripts. See each folder's README for setup instructions and how the results compare with the article.
